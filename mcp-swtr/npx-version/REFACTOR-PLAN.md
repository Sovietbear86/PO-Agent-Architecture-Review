## 🔴 Критические — требуют немедленного исправления

### P0. Отключена проверка TLS (глобально)

**Файл:** `src/index.ts:10`

```typescript
process.env.NODE_TLS_REJECT_UNAUTHORIZED = "0";
```

**Проблема:** Отключает проверку сертификата глобально для ВСЕХ HTTPS-запросов процесса. Production-окружение без HTTPS-валидации — Man-in-the-Middle атака возможна.

**Решение:** Сделать флаг конфигурируемым через переменную окружения. Не перезаписывать `NODE_TLS_REJECT_UNAUTHORIZED`, если он уже задан; использовать опцию `rejectUnauthorized` на уровне `fetch`.

**Затраты:** ~15 мин

---

### P1. Cookie `api_swtr_as21=true` хардкожен

**Файл:** `src/api/client.ts:33`

```typescript
Cookie: "api_swtr_as21=true";
```

**Проблема:**

- Специфичный session-cookie корпоративного портала — хрупкий и непрозрачный
- Cookie без `Secure`, `HttpOnly` флагов
- Пользователь не знает, что отправляется этот cookie

**Решение:** Вынести в конфигурацию (env) или убрать, если API работает без него. В любом случае — документировать.

**Затраты:** ~15 мин

---

### P2. Нет обработки ошибок API

**Файлы:** `src/api/client.ts`, все `src/domains/*.ts`

**Проблема:** Доменные функции пробрасывают HTTP-ответ как есть. 401/403/500 и таймауты доходят до пользователя в сыром виде, без контекста.

**Решение:** Добавить минимальную обёртку в `SwtrClient`:

- HTTP-статусы 4xx/5xx → осмысленные сообщения с контекстом операции
- Таймауты → "API не ответил за N секунд"
- Идентификатор запроса для трейсинга (Request ID)

**Затраты:** ~1 час

## 🟡 Средние — рекомендуется к реализации

### P3. `register.ts` — монолитная регистрация (~511 строк)

**Файл:** `src/mcp/register.ts`

**Проблема:** 37 вызовов `server.registerTool(...)` с повторяющимся паттерном. Нарушение SRP.

**Решение:** Разбить по доменам: `registerUnits(server)`, `registerWiki(server)`, `registerTestCases(server)`, `registerTimesheet(server)`. Или вынести конфигурацию инструментов в массив объектов и регистрировать циклом.

**Затраты:** ~1 час

### P4. Версия хардкожена в `server.ts`

**Файл:** `src/server.ts:16`

```typescript
version: "1.0.0";
```

**Проблема:** При bump версии в `package.json` нужно не забыть поменять и здесь — source of truth рассинхронизируется.

**Решение:** Импортировать `version` из `package.json` (через `readFileSync` или esbuild `define`).

**Затраты:** ~15 мин

### P5. `SwtrClient` создаётся на каждый вызов инструмента

**Файл:** `src/mcp/register.ts:34-36`

```typescript
function client(): SwtrClient {
    return new SwtrClient();
}
```

**Проблема:** Каждый вызов инструмента парсит env-конфиг через `getConfig()`.

**Решение:** Создать один экземпляр при старте сервера и переиспользовать.

**Затраты:** ~30 мин

### P6. Graceful shutdown

**Файл:** `src/index.ts:21-23`

```typescript
main().catch((err) => {
    process.exit(1);
});
```

**Проблема:** Нет перехвата `SIGTERM` / `SIGINT` для корректного закрытия MCP-транспорта.

**Решение:** Добавить `process.on("SIGTERM", ...)` / `process.on("SIGINT", ...)` с закрытием транспорта.

**Затраты:** ~30 мин
