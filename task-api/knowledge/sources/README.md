# Источники базы знаний

База знаний сформирована на основании:

1. Корпоративной рассылки со списком участников и email.
2. HR-представления состава команды и ролей.
3. Файла `Команды_DataMarts_OLAP_пересмотр_ЗП_2026_v.1.0.xlsx`.
4. Файла `Команды_DataMarts_OLAP_пересмотр_ЗП_2026_обоснования.xlsx`.

Оригинальные Excel-файлы намеренно не включены в архив агента. В архив включена производная база знаний. При необходимости источники следует хранить отдельно в защищенном корпоративном каталоге.
