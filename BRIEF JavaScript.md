# Бриф: трекер задач (React SPA)

## Контекст

Команда разработки использует внешний трекер задач, но он избыточен
для небольших внутренних процессов. Нужен лёгкий инструмент для
управления задачами внутри команды --- без серверной инфраструктуры,
развёртываемый прямо в браузере.

## Что нужно построить

SPA для управления задачами внутри небольшой команды. Пользователь
создаёт задачи, назначает исполнителей, отслеживает статус и
фильтрует список. Данные хранятся в localStorage --- перезагрузка
страницы не сбрасывает список.

## Требования к реализации

- Стек: React 18+, TypeScript, Vite
- Тесты: Vitest + React Testing Library
- UI-фреймворк и внешние API --- не нужны

## Что не входит в scope

- Авторизация
- Серверная часть и внешний API
- Синхронизация между вкладками
