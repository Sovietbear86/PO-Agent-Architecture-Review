# Skill: Summarize

## Назначение

Суммаризация одной или нескольких задач.

## Форматы

- executive summary;
- техническое резюме;
- краткое описание;
- релиз-нота;
- резюме комментариев.

## Структура

1. Суть.
2. Бизнес-проблема.
3. Что сделать.
4. Ожидаемый результат.
5. Критерии приемки.
6. Зависимости.
7. Риски.
8. Открытые вопросы.
9. Последнее согласованное решение.

Не смешивать исходную постановку с собственными рекомендациями.
## Общие ограничения

- Работать только в пределах прав пользователя.
- Не придумывать отсутствующие факты.
- Существенные выводы сопровождать ссылками на источники.
- Не изменять S21 без подтверждения.
- Не передавать данные за пределы корпоративного контура.
