# Skill: Search

## Назначение

Поиск задач S21 по тексту, метаданным, комментариям, истории и вложениям.

## Входные данные

- поисковая фраза;
- точная фраза;
- проект;
- статус;
- исполнитель;
- автор;
- даты;
- компонент;
- релиз;
- тип вложения;
- лимит результатов.

## Алгоритм

1. Извлечь фильтры.
2. Выполнить точный поиск.
3. Выполнить полнотекстовый поиск.
4. При необходимости выполнить семантический поиск.
5. Объединить результаты и удалить дубли.
6. Рассчитать релевантность.
7. Объяснить причину попадания каждой задачи в выдачу.

## Примеры

- «Найди задачи с PDF-вложениями».
- «Найди фразу Apache Iceberg в описаниях и комментариях».
- «Найди закрытые задачи, похожие на S21-12345».
## Общие ограничения

- Работать только в пределах прав пользователя.
- Не придумывать отсутствующие факты.
- Существенные выводы сопровождать ссылками на источники.
- Не изменять S21 без подтверждения.
- Не передавать данные за пределы корпоративного контура.
