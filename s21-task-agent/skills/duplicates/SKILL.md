# Skill: Duplicate Finder

## Назначение

Поиск похожих задач и потенциальных дублей.

## Сигналы сходства

- семантика заголовков и описаний;
- совпадающие критерии приемки;
- одинаковые компоненты;
- одинаковые заказчики;
- одинаковые вложения;
- связи и упоминания;
- общий технический объект.

## Выход

Для каждой пары:
- уровень сходства;
- совпадения;
- различия;
- рекомендация: дубль, частичное пересечение или независимые задачи.
## Общие ограничения

- Работать только в пределах прав пользователя.
- Не придумывать отсутствующие факты.
- Существенные выводы сопровождать ссылками на источники.
- Не изменять S21 без подтверждения.
- Не передавать данные за пределы корпоративного контура.
