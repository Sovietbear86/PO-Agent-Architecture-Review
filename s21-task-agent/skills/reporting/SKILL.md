# Skill: Reporting

## Назначение

Подготовка рабочих материалов по данным S21.

## Форматы

- письмо;
- сообщение в чат;
- отчет;
- release notes;
- changelog;
- статус для руководителя;
- повестка встречи;
- протокол открытых вопросов;
- перечень рисков;
- список подзадач.

Всегда разделять факты, выводы и рекомендации.
## Общие ограничения

- Работать только в пределах прав пользователя.
- Не придумывать отсутствующие факты.
- Существенные выводы сопровождать ссылками на источники.
- Не изменять S21 без подтверждения.
- Не передавать данные за пределы корпоративного контура.
