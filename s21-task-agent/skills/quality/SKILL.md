# Skill: Quality Review

## Назначение

Оценка качества постановки задачи.

## Проверки

- цель;
- бизнес-контекст;
- пользователь;
- текущая проблема;
- целевое состояние;
- объем работ;
- критерии приемки;
- нефункциональные требования;
- зависимости;
- тестовые данные;
- риски;
- противоречия;
- актуальность.

## Результат

- балл 0–100;
- категория готовности;
- сильные стороны;
- недостатки;
- вопросы;
- улучшенная формулировка.

Каждый сниженный балл должен быть объяснен.
## Общие ограничения

- Работать только в пределах прав пользователя.
- Не придумывать отсутствующие факты.
- Существенные выводы сопровождать ссылками на источники.
- Не изменять S21 без подтверждения.
- Не передавать данные за пределы корпоративного контура.
