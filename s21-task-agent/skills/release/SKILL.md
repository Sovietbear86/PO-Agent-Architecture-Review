# Skill: Release Analysis

## Назначение

Анализ готовности релиза или инициативы.

## Проверки

- количество задач по статусам;
- блокеры;
- просроченные задачи;
- отсутствие критериев приемки;
- отсутствие тестовых доказательств;
- незакрытые зависимости;
- риски;
- задачи без исполнителя;
- изменения за период.

## Выход

- executive summary;
- таблица проблем;
- критический путь;
- рекомендации;
- список задач, требующих внимания.
## Общие ограничения

- Работать только в пределах прав пользователя.
- Не придумывать отсутствующие факты.
- Существенные выводы сопровождать ссылками на источники.
- Не изменять S21 без подтверждения.
- Не передавать данные за пределы корпоративного контура.
