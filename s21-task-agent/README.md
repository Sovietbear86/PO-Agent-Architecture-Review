# S21 Task Intelligence Agent

Субагент для GigaCode CLI, предназначенный для интеллектуального поиска и анализа задач в корпоративном таск-трекере S21.

## Что умеет

- искать задачи по ID, тексту, статусу, исполнителю, проекту и датам;
- искать задачи по наличию вложений заданного типа;
- извлекать текст из PDF, XLSX, DOCX, MSG/EML;
- искать фразы внутри вложений;
- суммаризировать задачу;
- оценивать качество постановки;
- находить похожие задачи и потенциальные дубли;
- анализировать комментарии, историю и зависимости;
- формировать отчеты по релизам и бэклогу.

## Важное ограничение

По умолчанию агент работает только на чтение. Изменение задач S21 не реализовано.

## Быстрый старт

1. Скопируйте `.env.example` в `.env`.
2. Заполните параметры подключения к тестовому контуру S21.
3. Реализуйте методы адаптера в `src/s21_agent/connectors/s21_client.py`.
4. Установите зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

5. Проверьте конфигурацию:

```bash
python scripts/validate_config.py
```

6. Запустите локальную демонстрацию:

```bash
python scripts/demo.py
```

## Подключение к GigaCode CLI

Файл `AGENT.md` содержит системные инструкции агента. Каталог `skills/` содержит специализированные навыки. Способ регистрации агента и инструментов необходимо привязать к принятому в вашей версии GigaCode CLI механизму расширений, MCP или локальных tool-серверов.

Рекомендуемый вариант интеграции:

```text
GigaCode CLI
    -> S21 Task Intelligence Agent
        -> MCP/tool adapter
            -> S21 API
            -> Attachment processors
            -> Search index
```

## Структура

- `AGENT.md` — главный системный промпт;
- `skills/` — специализированные навыки;
- `config/` — профили оценки и настройки поиска;
- `src/` — Python-каркас;
- `prompts/` — шаблоны анализа;
- `tests/` — тесты;
- `eval/` — контрольные запросы;
- `docs/` — архитектура, безопасность и эксплуатация.

## Безопасность

- не храните токены в репозитории;
- не логируйте cookies, пароли и API-ключи;
- не отправляйте корпоративные данные во внешние LLM;
- выполняйте запросы от имени текущего пользователя;
- не обходите права S21;
- не запускайте макросы и исполняемые объекты из вложений.
