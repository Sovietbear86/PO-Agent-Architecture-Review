# Архитектура

## Рекомендуемый вариант

```text
GigaCode CLI
  -> Agent instructions
  -> Tool/MCP server
      -> S21 API
      -> Attachment processors
      -> Search index
      -> Audit and metrics
```

## Потоки

### Простой поиск

1. Агент извлекает фильтры.
2. Вызывает `s21_search_tasks`.
3. Ранжирует результаты.
4. Возвращает таблицу со ссылками.

### Поиск по вложениям

1. Находит кандидатов по типу файла.
2. Получает метаданные вложений.
3. Скачивает только релевантные файлы.
4. Извлекает текст.
5. Ищет фрагменты.
6. Возвращает задачу, файл и место совпадения.

### Семантический поиск

На первом этапе можно выполнять поверх ограниченного набора кандидатов.
Для промышленного масштаба рекомендуется отдельный корпоративный индекс.
