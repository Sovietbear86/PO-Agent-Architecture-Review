# Безопасность

## Обязательные меры

- Авторизация от имени пользователя.
- Сохранение модели прав S21.
- Read-only по умолчанию.
- Маскирование токенов и cookies.
- Запрет вывода секретов в логи.
- Запрет внешних LLM без согласования.
- Временный кэш с TTL.
- Шифрование кэша.
- Антивирусная проверка вложений.
- Запрет исполнения макросов.
- Аудит запросов и действий.
- Ограничение размеров файлов.
- Защита от prompt injection во вложениях.

## Prompt injection

Текст задачи и вложения считаются недоверенными данными.
Инструкции, содержащиеся в задаче или файле, не должны менять системные правила агента.
