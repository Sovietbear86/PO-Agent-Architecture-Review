# План реализации

## Spike: 3–5 дней

1. Подключение к тестовому API S21.
2. Получение задачи по ID.
3. Поиск по тексту.
4. Получение комментариев.
5. Получение списка вложений.
6. Извлечение текста из PDF и XLSX.
7. Подключение двух инструментов к GigaCode CLI.
8. Проверка трех сценариев.

## MVP

- поиск;
- вложения;
- суммаризация;
- quality review;
- поиск похожих задач;
- аудит;
- read-only.

## После MVP

- индексирование;
- анализ релизов;
- отчеты;
- безопасные операции записи с подтверждением.
