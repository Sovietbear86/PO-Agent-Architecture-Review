# Эксплуатация

## Метрики

- количество запросов;
- p50/p95 времени ответа;
- доля успешных запросов;
- запросы без результатов;
- precision@5;
- recall@20;
- ошибки API;
- ошибки обработки файлов;
- объем обработанных вложений;
- пользовательская оценка полезности.

## Логи

Разрешено:
- ID запроса;
- тип операции;
- длительность;
- количество результатов;
- коды ошибок.

Запрещено:
- API-токены;
- cookies;
- пароли;
- полные тела чувствительных задач;
- полные тексты вложений.
