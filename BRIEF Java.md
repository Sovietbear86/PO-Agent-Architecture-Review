# Бриф: сервис управления задачами

## Контекст

Команда разработки использует внешний трекер задач, но он избыточен для небольших внутренних
процессов. Нужен лёгкий сервис, который можно развернуть самостоятельно и интегрировать
с другими внутренними инструментами через API.

## Что нужно построить

REST API для управления задачами внутри небольшой команды.

Сервис должен позволять создавать задачи, назначать их на исполнителей, отслеживать статус
и фильтровать список задач по нужным параметрам.
Данные можно хранить в памяти --- персистентность не требуется.

## Требования к реализации

- Язык: Java 17+, сборка: Maven, фреймворк: Spring Boot 3 + Spring Web
- Сервис используется через HTTP API --- UI не нужен
- Код должен быть покрыт тестами (JUnit 5 + MockMvc)

## Что не входит в scope

- Аутентификация и авторизация
- Персистентное хранилище (Spring Data, Hibernate, база данных)
- Уведомления и интеграции с внешними системами
