## Фазы анализа
1. **Рефакторинг** — что можно упростить без изменения поведения.
2. **Декомпозиция** — как разбить на меньшие части.
3. **Проблемы** — производительность, доступность, edge cases.
4. **Тесты** — что не покрыто, что легко сломать.
5. **Документация** — что неочевидно и требует описания.# Frontend Component Analyzer Skill

## Overview
This skill provides frontend component analysis capabilities.

## Capabilities
- Analyze React component structure and props
- Identify unused dependencies and code
- Review component composition and patterns
- Check accessibility and best practices

## Usage
Invoke with `/analyze-component` command followed by file path or component code.

## Supported Frameworks
- React 18+
- TypeScript
