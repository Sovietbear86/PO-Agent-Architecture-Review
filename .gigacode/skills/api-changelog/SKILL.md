## Структура changelog
### Добавлено
- Новые эндпойнты и поля.

### Изменено
- Переименованные поля, изменённые типы, новые обязательные параметры.

### Удалено / Deprecated
- Убранные или устаревшие поля с указанием замены.

## Правила
- Сравнивай только публичный контракт, не внутреннюю реализацию.
- Отмечай breaking changes отдельно.
