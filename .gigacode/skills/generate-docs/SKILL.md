## Структура документа
1. Назначение — что делает модуль / функция / сервис.
2. Входные данные и выходные данные.
3. Зависимости и ограничения.
4. Примеры использования.

## Правила
- Не домысливай детали, которых нет в коде.
- Пиши кратко: одна мысль — один абзац.
- Не включай внутренние детали реализации, если они не нужны пользователю.
