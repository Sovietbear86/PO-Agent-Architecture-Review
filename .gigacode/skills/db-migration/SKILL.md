description: Генерирует SQL-миграцию по описанию изменений схемы.
  Используй, когда нужно добавить таблицу, изменить колонку или добавить индекс.
---

## Правила генерации
- Всегда создавай `up` и `down` миграции.
- Новые NOT NULL колонки добавляй с DEFAULT или в два шага.
- Индексы создавай CONCURRENTLY, чтобы не блокировать таблицу.
- Называй файл: `<timestamp>_<краткое_описание>.sql`

## Формат
```sql
-- up
ALTER TABLE ...;

-- down
ALTER TABLE ...;
```
